# 前瞻模擬追蹤（2026-11-26 已實作：`src/track.py`）

實作補充（與下方草稿不同或新增之處）：
- 全市場訊號日前 `track.prefetch_days` 個交易日起，每天在 `track.prefetch_minutes` 內補資料；訊號日資料涵蓋率 < `track.min_coverage` 就順延（最多 `track.max_defer_days`），超過記 skipped
- 訊號晚於訊號日才記錄時，紙上成交在「記錄日之後第一個交易日開盤」，不回補已經過去的開盤
- 淨值每天依凍結的訊號重算，只追加新日期；重算結果與先前紀錄差距 > 0.5% 時，摘要會標註
- 配對隨機組 5 組（固定 seed），同池、同檔數、同換手
- 基本面為記錄當下的 FinMind 版本（沒有歷史版本）
- 週檢討（LINE 推播仍可用）附追蹤摘要；只報淨值、報酬、回撤 vs 0050 / 隨機，不列下一期要買的股票

保留期已消耗；一個選股規則要有「真正的樣本外證據」，只能從登記之後才發生的資料來。
這個模組把使用者選定的策略檔放進每日排程，用紙上交易持續記錄，紀錄寫入後不改。

## 使用方式（預定）
```
python -m src.cli track add strategies/lab/<名稱>.yaml     # 開始追蹤（記下開始日與規則雜湊）
python -m src.cli track list                                # 目前追蹤中的策略與成績
python -m src.cli track stop <名稱>                          # 停止（紀錄保留，不刪）
```

## 規則
- 任何策略檔都可以追蹤（通過實驗室與否都行），但報告會標示它在實驗室的判定
- 追蹤開始後，策略檔的規則雜湊被鎖定；檔案若被改，追蹤停止並在報告中標註（要改規則就另開新追蹤）
- 每個調整日（依 rebalance_days 從開始日算）在 17:30 排程中：用當天收盤資料選股、記錄「隔天開盤要換成哪些股票」；隔天用實際開盤價計算成交（含手續費、證交稅、成交量上限）
- 紀錄 `data/track/<名稱>.csv` 只追加；每日記下淨值、持股、與同期 0050 含息、配對隨機組（固定 seed）
- 每週檢討報告加一段：各追蹤策略至今報酬、Sharpe、最大回撤 vs 0050；追蹤未滿一年或未經歷一次 10% 以上的大盤回檔時，明寫「樣本不足，不能下結論」
- 只是紙上模擬，不連任何券商、不產生下單指令、不推播「該買什麼」——推播只報「追蹤中的策略本週淨值」
