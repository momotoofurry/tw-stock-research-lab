# 策略實驗室（設計）

目的：讓使用者用設定檔描述選股想法，工具依 `docs/研究流程.md` 自動做完整檢驗並記錄每一次嘗試。
工具不給買賣建議；只回答「這個想法在開發期的證據過不過門檻」。

## AI 提出的想法（2026-11-26 起，`/tw-idea`）
- 策略檔加 `author: ai`，並必填 `who_pays`（誰在賠錢）、`source`（文獻或已知現象）、`family`（想法家族）；使用者的策略也可以填這些欄位
- 這些都是文字欄位，不進規則雜湊；帳本格式不變，提出者從策略檔讀
- 每月最多新登記 `lab.ai_monthly_budget`（預設 2）個 AI 規則；同一規則重跑不受限
- 墓園規則：同 family 已有 AI 策略「不通過」，就不能再提同家族的新規則（防止換參數再試）
- 判定門檻、Bonferroni 的規則數 N 對所有提出者一視同仁；N 包含使用者與 AI 所有試過的規則
- AI 寫好策略檔後必須經使用者同意才執行；通過也只進前瞻追蹤，不是推薦

## 使用方式
```
python -m src.cli lab strategies/lab/<名稱>.yaml
```
- 只用開發期（`evaluation.holdout_start` 之前），**沒有** `--holdout` 選項；保留期已消耗，新規則的樣本外證據只能來自前瞻追蹤
- 輸出 `reports/lab/<名稱>_<日期>.md`，並在 `reports/lab/trials.csv` 追加一列（只追加不改）

## 策略檔格式（事前登記）
```yaml
name: rev_growth_quality
registered: 2026-11-16          # 第一次登記日；之後改規則要另存新檔、新名稱
hypothesis: 營收持續成長且獲利的公司，市場反應不足，之後一年仍有超額報酬
rationale: 分析師與法人對中小型股的覆蓋不足，資訊擴散慢
fails_if: 營收成長只是循環高點；或大型權值股主導全市場報酬時
universe: full                  # 全市場候選（含下市股），每個調整日用當天門檻篩
rebalance_days: 63
top_n: 10
lookback: 126                   # 動能回看天數（mom 因子用）
filters:                        # 全部要成立（AND）
  - {factor: yoy3, op: ">", value: 0.10}
  - {factor: eps_ttm, op: ">", value: 0}
rank_by: {factor: yoy3, order: desc}
```
- 可用因子（第 t 天收盤時已知）：`mom63`、`mom`（lookback 日漲幅）、`yoy3`（近 3 個月營收年增）、`eps_ttm`（近四季 EPS）、`turnover`、`close`
- 估值因子（2026-11-16 加入，都由已載入的資料自算、只用第 t 天已知的值）：
  - `pe`：未還原收盤 /（`eps_ttm` 依季末之後到 t 的減資 / 分割換算成目前每股）；`eps_ttm` ≤ 0 時為空值，任何 `pe` 條件都不成立（虧損股被排除）
  - `dy`：除息日在 (t − 365 天, t] 的每股股利（除權息參考價差，**含配股折現金**，不是純現金殖利率）÷ 該筆之後到 t 的股數乘數（減資 / 分割）÷ 未還原收盤；沒配息為 0
  - 兩者都用「過去」的獲利與股利：景氣循環股在高峰過後會顯得極便宜（例：2609 在 2023-03-31 的 pe 1.0、dy 31%，來自 2021~22 航運高峰），用 `pe <`、`dy >` 篩選時會偏好這類股票
  - 股價淨值比尚未加入（需要資產負債表，全市場要另外下載）
  - 限制：EPS 與股利是 FinMind 目前的版本，不是當時公告的原始數字（見 `data/vintages/`）
- 價格 / 流動性門檻沿用 `rank.min_price`、`rank.full_min_turnover`

## 檢驗內容（門檻固定在程式與 `docs/研究流程.md`，策略檔不能改）
| 項目 | 通過條件 |
|---|---|
| 對 0050 含息 | Sharpe 較高，且最大回撤不比 0050 深超過 10 個百分點 |
| 配對隨機選股（同池、同檔數、同換手） | 年化與 Sharpe 都在前 5% |
| 鄰近參數（top_n、lookback、rebalance_days、數值門檻各 ±20%） | 至少 3/4 組 Sharpe 勝過 0050 |
| 前後兩段 | 兩段 Sharpe 都勝過 0050 |
| 兩倍成本 | Sharpe 仍勝過 0050 |
| 下市持股歸零 | Sharpe 仍勝過 0050 |
| 拿掉貢獻最大的 3 檔 | Sharpe 仍勝過 0050 |
| 拿掉最好的一年 | Sharpe 仍勝過 0050 |

## 試驗帳本（防止「試到成功為止」）
- `reports/lab/trials.csv`：每次執行追加一列（時間、名稱、規則雜湊、年化、Sharpe、隨機 p 值、判定、程式版本、資料快照雜湊）
- 報告列出「至今共試過幾個不同的規則（依規則雜湊）」，並給 Bonferroni 修正後的 p 值（p × 規則數）；修正後不顯著就不算通過
- 同一規則重跑不增加計數；改任何一個參數都算新的規則

## 驗證實驗室本身
- 把已淘汰的排名規則寫成策略檔，實驗室結果必須和 `rank_study` 的開發期數字一致（年化 29.8%、Sharpe 0.88）
- 特徵截斷不變性：截斷未來資料後，過去每個調整日選出的股票不變

## 之後
- 通過的規則 → 前瞻模擬追蹤（每日排程紙上交易，紀錄不可改）
- 白話報告可交給本機 LLM 撰寫（數字由程式計算、數字查核器把關）
